# CADET User Manual

This manual is organized by feature so you can jump directly to the workflow you need.

Use this manual when you want a full reference for setup, execution, publishing, and diagnostics. If you are brand new to CADET, begin with the Getting Started guide first, then return here for detailed workflows.

Feature markers used throughout:
- <span style="color: #D4AF37;">[Pro]</span> Available only in CADET Pro.
- Unmarked sections apply to both CADET Lite and CADET Pro.

## How To Use This Manual

- Follow chapters in order for first time setup.
- Jump to workflow chapters for day to day operations.
- Use Troubleshooting for incident response and recovery.
- Keep this manual open while configuring profiles and queue jobs.
